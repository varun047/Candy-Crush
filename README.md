# Project Name
Candy-Crush
=================
A simple game built with JavaScript, where the player crushes candies to progress through levels.

## About
Candy-Crush is a fun and addictive puzzle game that challenges players to match and eliminate candies in various colors and patterns. The game features a variety of levels, increasing difficulty as the player progresses.

## Tech Stack
### Frontend
* JavaScript (ES6+)
* HTML/CSS (for styling and structure)

### Backend
None

### Dependencies
None

## Features
* Simple and addictive gameplay
* Various levels with increasing difficulty
* Colorful candy graphics
* Smooth animations and transitions

## Getting Started
To run the game, follow these steps:

1. Clone the repository: `git clone https://github.com/your-username/Candy-Crush.git`
2. Navigate to the project directory: `cd Candy-Crush`
3. Open the `index.html` file in a web browser.

## Project Structure

* `background.jpg`: The background image of the game
* `candy.css`: The stylesheet for styling the candies and other elements
* `candy.js`: The main JavaScript file that handles gameplay logic and functionality
* `images`: A folder containing various candy graphics
	+ Images representing different types of candies (e.g. Blue-Striped-Horizontal.png)
	+ Blank images (for level completion or end screens)
